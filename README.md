# Quantum Holding Consulting : site vitrine

Site statique (un seul fichier `index.html`, sans dépendance à installer).

## Mise en ligne gratuite avec GitHub Pages
1. Créez un dépôt public sur github.com (par exemple `quantum-holding-consulting`).
2. « Add file » puis « Upload files » : déposez le contenu de ce dossier, puis « Commit changes ».
3. « Settings » puis « Pages » : Source « Deploy from a branch », branche `main`, dossier `/ (root)`, « Save ».
4. Après 1 à 2 minutes, le site est en ligne sur `https://VOTRE-NOM.github.io/quantum-holding-consulting/`.

## Domaine quantumholdingconsulting.com
Dans « Settings » puis « Pages » : renseignez le domaine personnalisé et activez HTTPS, puis créez chez votre registrar quatre enregistrements A (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) et un CNAME `www` vers `VOTRE-NOM.github.io`.

## Formulaire de contact
Il envoie les messages à quantumholdingconsulting@gmail.com via FormSubmit. Au premier envoi, FormSubmit envoie un e-mail d’activation à cette adresse : cliquez sur le lien de confirmation, puis refaites un test.
